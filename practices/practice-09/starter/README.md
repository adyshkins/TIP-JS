# Стартовые файлы ПР9

Перенести только вложенную папку `practice-09` в корень личного репозитория с решениями. Предыдущие работы сохраняются.

Из `practice-09` выполнить `npm ci`, затем `npm start`. Проверка окружения: http://127.0.0.1:5505/api/health.

Основное задание находится в [методичке](../README.md). Реализовать `src/validation.js`, `src/task-service.js` и `src/routes.js`. До выполнения задания часть запросов возвращает 501, а проверки не проходят — это ожидаемое состояние заготовки. Готового решения здесь нет.

`README.md` внутри `practice-09` — шаблон отчёта. Зависимости `node_modules` не переносятся и не публикуются.
