# Стартовые файлы ПР13

Перенести только вложенную папку `practice-13` в корень личного репозитория. [Методичка](../README.md).

Проект содержит завершённую базовую реализацию API ПР12, конфигурацию `node:test`, встроенного покрытия Node.js, ESLint и Prettier. Необходимо заменить все `test.todo` полноценными проверками, дополнить набор по индивидуальному варианту и добиться успешного `npm run quality`.

DB-тест запускается отдельно на собственной учебной базе через локальный `.env`. Пароль, `.env`, `node_modules`, журналы и каталог покрытия в Git не добавляются.
