# Стартовые файлы ПР12

Перенести только вложенную папку `practice-12` в корень личного репозитория. [Методичка](../README.md).

Проект содержит готовый HTTP-контракт ПР10, правильную схему ПР11 и заготовку PostgreSQL-хранилища. Для выполнения необходимо заменить TODO в `src/query-builders.js` и `src/store.js`, создать локальный `.env`, установить зависимости и выполнить проверки.

Пароль базы, `.env`, `node_modules` и журналы в Git не добавляются. `sql/01_schema.sql` и `sql/02_seed.sql` предназначены для новой пустой базы; для уже выполненной ПР11 повторно запускать их не требуется.
