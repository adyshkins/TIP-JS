# Стартовые файлы ПР6

Для выполнения работы копируется **вложенная папка `practice-06` целиком** в корень личного репозитория с решениями.

```text
TIP-JS/                                  # репозиторий курса
└── practices/practice-06/starter/
    └── practice-06/                    # копируется эта папка

личный-репозиторий/
├── practice-01/
├── practice-02/
├── practice-03/
├── practice-04/
├── practice-05/
└── practice-06/                        # результат копирования
```

Внешние папки `practices` и `starter` в личный репозиторий переносить не требуется. Повторный `git init` также не нужен.

Заготовка не содержит готового клиентского решения. В ней предоставлены:

- изменяемый учебный HTTP API;
- сервер статических файлов и совместный сценарий запуска;
- HTML-разметка и стили приложения;
- DOM-адаптер и таблица вариантов;
- контракты модулей с `TODO`;
- серверные, модульные, интеграционные и браузерные проверки;
- шаблон отчёта в `practice-06/README.md`.

После копирования выполняются команды:

```bash
cd practice-06
npm run check:api
npm start
```

Устанавливать npm-зависимости не требуется. Исходный готовый API проходит 23 серверные проверки. Клиентские проверки до реализации модулей завершаются ошибками `Не реализовано` — это ожидаемое состояние заготовки.

Полное задание: [методические указания к ПР6](../README.md).
