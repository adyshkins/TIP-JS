# Стартовые файлы ПР4

[К методичке](../README.md)

Содержимое вложенной папки `practice-04` предназначено для личного репозитория с решениями. Необходимо скопировать **папку `practice-04` целиком** в корень личного репозитория рядом с предыдущими работами. Этот поясняющий README переносить не требуется.

После копирования необходимо перенести из выполненной ПР3 реализации `src/data.js`, `src/task-service.js`, `src/task-selectors.js` и `src/task-view.js`. Затем:

- добавить `updateTask` в `task-service.js`;
- добавить действие `edit` в карточку из `task-view.js`;
- реализовать новые модули `form-validation.js` и `task-storage.js`;
- завершить обработчики и отрисовку в новом `main.js`.

Файл `main.js` из ПР3 поверх нового файла не копируется. В ПР4 изменились начальная загрузка, обработка формы и сохранение данных.

Из папки `practice-04`:

```bash
npm test
npm start
```

Установка пакетов не требуется. По умолчанию приложение доступно по адресу `http://127.0.0.1:5504/`, проверки — `http://127.0.0.1:5504/checks.html`.

`README.md` внутри переносимой папки — шаблон собственного отчёта. Ожидаемые результаты в нём необходимо заменить фактическими после запуска.
