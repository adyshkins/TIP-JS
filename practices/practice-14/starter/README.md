# Стартовые файлы ПР14

Перенести только вложенную папку `practice-14` в корень личного репозитория. [Методичка](../README.md).

Starter содержит завершённую базу проверок ПР13, заготовки релизного слоя, Docker Compose, GitHub Actions, smoke-проверку и шаблоны эксплуатационной документации. Необходимо реализовать 14 тестов с маркером `test.todo`, завершить модули `health`, `logger`, `lifecycle`, расширить конфигурацию, связать их с приложением и заполнить релизные документы.

В Git не добавляются `.env`, пароли, `node_modules`, журналы, покрытие и данные PostgreSQL. Исходное состояние специально не проходит итоговый gate: 41 тест завершён, 14 помечены `todo`.
