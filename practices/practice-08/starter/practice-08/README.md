## Запуск

Из папки `practice-08`: `npm ci`.
Первый терминал: `npm run api`. Второй: `npm run dev`.
API: http://127.0.0.1:5505/api. Интерфейс: http://127.0.0.1:5173/.

При смене порта API указать адрес в `.env` по образцу `.env.example` и перезапустить Vite. Для сборки: `npm run build`, затем `npm run preview`; API остаётся запущенным.
