# Стартовые файлы ПР8

Папка `practice-08` переносится целиком в корень личного репозитория. Предыдущие работы сохраняются. Инструкции: [методичка ПР8](../README.md).

Внутри `practice-08` выполнить `npm ci`. В первом терминале запустить `npm run api`, во втором — `npm run dev`. Адрес интерфейса: http://127.0.0.1:5173/. API: http://127.0.0.1:5505/api.

Готовы сервер, HTTP-клиент, предметный API, базовые компоненты и тестовая инфраструктура. Хук `src/hooks/useTaskData.js` необходимо реализовать. Вместо базовых компонентов можно адаптировать собственные решения ПР7, сохранив контракты.

`npm run check:api` и `npm run check:integration` проверяют готовую часть. `npm run check:react` проверяет решение и до реализации хука завершается ошибками. Полный прогон — `npm test`; сборка — `npm run build`.

`package-lock.json` и `.env.example` сохраняются в репозитории. `node_modules`, `dist` и `.env` не публикуются.
