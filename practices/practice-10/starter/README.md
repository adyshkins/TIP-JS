# Стартовые файлы ПР10

Перенести только вложенную папку `practice-10` в корень личного репозитория. ПР8 и ПР9 сохраняются. Методичка — [здесь](../README.md).

Здесь сервер на Express: операции чтения готовы, операции записи оставлены для реализации в `src/task-validation.js`, `src/store.js`, `src/write-routes.js`. Команды из `practice-10`: `npm ci`, `npm start`, `npm test`.

Для интерфейса используется **выполненная собственная ПР8** из соседней папки. Её готовый учебный API запускать не нужно: вместо него работает сервер ПР10. React-заготовка ПР8 с незавершённым хуком не является готовым клиентом.

`checks/support` содержит неизменённые HTTP-модули ПР8 для автоматических интеграционных проверок. Они не заменяют React-интерфейс и не требуют Vite для выполнения тестов.
