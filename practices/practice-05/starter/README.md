# Стартовые файлы ПР5

В папке [`practice-05`](./practice-05/) находится переносимая заготовка практической работы.

В личный репозиторий с решениями необходимо скопировать именно вложенную папку `practice-05` целиком. Внешние папки `practices`, `practice-05` и `starter` из репозитория курса копировать не требуется.

После переноса структура личного репозитория дополняется так:

```text
личный-репозиторий/
├── practice-01/
├── practice-02/
├── practice-03/
├── practice-04/
└── practice-05/
    ├── README.md
    ├── package.json
    ├── api/
    ├── checks/
    ├── examples/
    └── src/
```

Заготовка содержит готовый учебный HTTP API, примеры, проверки и незавершённые модули клиента. Готовый сервер в `api/` изменять для обязательной части не требуется.
