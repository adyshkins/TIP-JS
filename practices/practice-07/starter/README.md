# Стартовые файлы ПР7

Переносится **папка `practice-07` целиком** в корень личного репозитория рядом с предыдущими работами. Внешние папки `practices` и `starter` не копируются.

Внутри `practice-07` выполняются `npm ci` и `npm run dev`. Папки `node_modules` и `dist` не коммитятся. `package-lock.json` переносится вместе с заготовкой и сохраняется в личном репозитории.

Начальная страница показывает заготовку. Предметные функции и компоненты предстоит реализовать по [методичке](../README.md). `npm test` до реализации завершается ошибками `Не реализовано`; сборка заготовки сама по себе не означает выполнение задания.
