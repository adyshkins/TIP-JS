# Стартовые файлы ПР3

[К методичке](../README.md)

Содержимое папки `practice-03` предназначено для личного репозитория с решениями.
Необходимо скопировать **папку `practice-03` целиком** в корень этого репозитория, рядом с `practice-01` и `practice-02`.
Этот поясняющий README переносить не требуется.

После копирования заменить `src/task-service.js` и `src/data.js` внутри новой работы собственными файлами из ПР2. В `task-service.js` здесь находятся заглушки, а не готовая реализация. `main.js` из ПР2 не переносится.

Из папки `practice-03`:

```bash
npm run check:service
npm start
```

Установка пакетов не требуется. Открыть адрес из терминала, по умолчанию `http://127.0.0.1:5503/`.

HTML, CSS, локальный сервер, эксперименты и проверки предоставляются готовыми. В модулях отображения, отбора и управления оставлены задания. До их реализации сообщение о заглушке и непройденные браузерные проверки ожидаемы.

`README.md` внутри `practice-03` — шаблон собственного отчёта. Фактические результаты необходимо заполнить после запуска.
