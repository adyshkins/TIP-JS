# Демонстрация к Лекции № 2

Пример показывает один полный цикл работы интерактивного интерфейса: событие пользователя изменяет состояние, состояние сохраняется и затем отображается в DOM.

[К конспекту лекции](../README.md) · [К описанию курса](../../../README.md)

## Запуск

Из этого каталога:

```bash
npm start
```

После запуска необходимо открыть:

```text
http://127.0.0.1:5502/
```

Зависимости устанавливать не требуется. Для проверки синтаксиса:

```bash
npm run check
```

## Состав примера

| Файл | Назначение |
|---|---|
| `index.html` | Семантический каркас формы, фильтров и списка. |
| `styles.css` | Оформление состояний и адаптация к узкому экрану. |
| `app.js` | Состояние, DOM, события, валидация и `localStorage`. |
| `serve.mjs` | Локальный HTTP-сервер на стандартных модулях Node.js. |
| `package.json` | Команды запуска и проверки. |

Данные сохраняются под ключом `tip-js:lecture-02:topics`. Кнопка сброса удаляет только этот ключ и восстанавливает исходный набор.
